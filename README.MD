# Template für Visual Studio Code

Diese Vorlage dient als Grundlage zum Starten eines SEGA Mega Drive Spiels mit dem SGDK unter Visual Studio Code.

Folgende Voraussetungen braucht ihr:
* Visual Studio Code
* Extensions in VS Code: Genesis Code von zerasul, C/C++ Extension Pack - DevTools
* SGDK von Stephane-D (auf github)
* Gens Emulator
